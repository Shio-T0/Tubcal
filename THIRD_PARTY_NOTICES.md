`server/sources/hianime.py` uses the method ani-cli (5.1) uses to reach episode
streams:
- which hianime.at pages to ask;
- that the ZokoAnime embed carries the player config;
- the `otaku-embed-v1` key that config is XOR-ed with.

script, but its page patterns necessarily match the same pages.

## The Android app (`android/`)

The APK contains Tubcal's own server and web code, plus the following. Settings →
About in the app shows these notices and the full lists.

### anipy-api (vendored)

`android/app/src/main/python/anipy_api/` is the anipy_api package of release
3.8.21, **unmodified**. pip can't install that release on Android, because some of
its declared dependencies have no Android build, and the parts Tubcal uses import
none of them. Its `LICENSE` (GPL-3.0) and `NOTICE` sit next to it.

### weeb-cli (vendored, a subset)

`android/app/src/main/python/weeb_cli/` holds a subset of release 3.0.0's weeb_cli
package. The files present are unchanged. `NOTICE` lists what was left out, and
when. Its `LICENSE` (GPL-3.0-only) sits next to it.

### Python runtime and packages

The app runs CPython 3.11 through [Chaquopy](https://github.com/chaquo/chaquopy)
(MIT). CPython is under the PSF License Version 2. pip installs these packages
into the APK (`android/app/build.gradle.kts`):
- flask, requests, feedparser, python-dotenv, yt-dlp, pycryptodomex;
- beautifulsoup4, dataclasses-json, m3u8, pycountry, simpleeval;
- and their dependencies.

They are under licences such as BSD-3-Clause, Apache-2.0, MIT and Unlicense. Two
are copyleft: pycountry is LGPL-2.1-only and certifi is MPL-2.0. Both can be
combined with GPL-3.0, and both ship as Python source you can replace.
`android/tools/gen-licenses.py` writes each package's version, licence and licence
text to `android/app/src/main/legal/python-licenses.txt`, which ships in the app.

`android/app/src/main/python/Levenshtein.py` is this project's own small stand-in
for the `Levenshtein` package; it contains none of that package's code.
