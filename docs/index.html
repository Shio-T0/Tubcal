02 The daily paper

The Edition

A front page composed on this machine. It degrades like a real press: every rung of the ladder prints a usable paper. Flip what's installed and watch the same morning's news re-set itself.

What's installed
  1. WireURL hard-links cluster; headlines + numbers
  2. Semanticthe same story, found across rooms
  3. Editedwritten up by the copy desk

  1. Background threadBuilt once a dayClustering, ranking and writing all happen off the request path.
  2. editions tableOne JSON payloadEvery paper is a single row, so back issues are free.
  3. GET /api/edition/latestOne SQLite readOpening the page never waits on a model.
  4. The copy desk≤ 6 model callsTime-boxed, gated by a citation validator, with a template fallback — the paper cannot invent a story.
03 One global player

A theatre, not a pop-up.

Every video — from any room — plays in one player, straight from YouTube's own streams: real 1080p, no account, no embed. The room goes dark, the picture's colours glow around it, and the seek bar knows the video. Click the screen, then use the keys.

05 Seven skins

The look

Each skin is one [data-theme] block overriding design tokens — so every component restyles for free, down to the editor buffer and the terminal's ANSI palette. Each card below is wearing its own skin. Pick one; this whole page follows.

In the app your choice is injected server-side into index.html, so there's no flash of the wrong theme on first paint. This page does the same with a two-line script in its <head>.

06 Runs on localhost

Privacy, by wiring.

Binds to 127.0.0.1 and nothing else. Self-hosted fonts, no trackers, no analytics. Every YouTube read is anonymous — no cookies stored or sent, so there's no stable id linking your searches, feeds and playback.

your machine
127.0.0.1:5000
  • Flask serves the API and the built UI on one port
  • data/tubcal.db — one git-ignored SQLite file: subscriptions, settings, watch history, playback progress, saved items, OAuth tokens and every byte of Archive data
  • Ollama (optional) on 127.0.0.1:11434 — the models never leave the box
  1. YouTubeRSS feeds, InnerTube search, googlevideo streams — anonymous, cookie-less
  2. RedditRSS logged out; full data if you connect an OAuth app
  3. Hacker Newsthe Firebase API, and Algolia for search
  4. GitHubthe public REST API; your PAT only if you paste one
  5. AniListGraphQL with your own OAuth token
  6. HelpersInvidious for trending and fallback search, the anime scrapers while you watch, PyPI for the anipy-api self-update (TUBCAL_AUTO_UPDATE=0 stops it)
  7. Nothing elseno analytics, no trackers, no CDN fonts, no cloud relay
07 Three commands

Tune in.

You need Python ≥ 3.12, Node, and yt-dlp on your PATH. Everything else is optional and degrades quietly.

install & run
uv sync                                               # backend
cd frontend && npm install && npm run build && cd ..  # frontend
uv run python main.py                                 # → http://127.0.0.1:5000

Open the page, pick a channel, add a few YouTube channels and subreddits in Settings, and the rooms fill in.
